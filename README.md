# Смета автосервиса

Приложение для быстрого расчёта стоимости ремонта и услуг в автосервисе. Устанавливается на смартфон и компьютер, после установки работает без интернета.

## Возможности

- Выбор вида ремонта или услуги из каталога или добавление своей
- Запчасти и материалы: название, количество, цена
- Работа мастера: нормо-часы × стоимость нормо-часа
- Итоговая смета: работа, запчасти, наценка, скидка, НДС
- Два языка интерфейса: русский и английский (переключатель вверху страницы), выбор запоминается
- Валюта сметы: тенге (₸) или доллар ($); все суммы и итоги показываются в выбранной валюте, пересчёта по курсу нет
- Сохранение смет, повторное открытие и удаление
- Отправка клиенту: WhatsApp, Telegram, почта, копирование, печать и PDF
- Светлая и тёмная тема, вёрстка для телефона

## Установка как приложение

- **Android (Chrome):** откройте сайт, нажмите «Установить приложение» или меню ⋮ → «Установить приложение».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран Домой».
- **Компьютер (Chrome, Edge):** значок установки в адресной строке справа.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/ (root)`. Установка работает только по https, GitHub Pages его даёт.

## Настройка

- Каталог услуг: массив `CAT` в `index.html` (название по-русски, нормо-часы, название по-английски)
- Переводы интерфейса: словарь `EN` в `index.html` (ключ - русский текст, значение - английский)
- Нормо-час и ставка НДС по умолчанию: функция `blank()`; проверьте актуальную ставку НДС
- После изменений в файлах увеличьте номер версии `V` в `sw.js`, чтобы приложение обновилось у пользователей

Данные хранятся на устройстве и не синхронизируются между устройствами.
